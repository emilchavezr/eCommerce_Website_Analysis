## E-commerce Funnel Analysis

The goal of this project was to analyze user progression across an e-commerce funnel and highlight optimization opportunities at each stage.

### This submission includes:
- A Power BI dashboard with full-funnel tracking (Home → Confirmation)
- Breakdown by gender, device, and weekday
- A complete SQL script of queries used for funnel analysis
- Python script used for initial data cleaning
- Key KPIs and drop-off stages throughout the funnel

### Key Insights (more in the presentation):
- 50% of users drop between Home and Search
- Only 7.5% of users who reach Payment end up confirming
- Mobile users convert 4x better than Desktop
- Female users show a slightly higher confirmation rate
- The highest daily activity occurs on Thursdays

### Tools & Workflow:
This analysis was powered by a combination of:
- **Python** (for cleaning and data export)
- **SQL** (for aggregations and funnel logic)
- **Power BI** (for interactive data visualization)

All logic is traceable and reproducible. The `.pbix` file runs without external database connections.

### 📁 Data

All datasets included are anonymized and simulated for educational purposes.  
They were used to support SQL and Power BI analysis across funnel stages.
